# C-Mind（心图）交互设计评审报告

> 评审范围：v0.1.0 全部主要交互（侧栏/标签页/画布/节点/图片/Git/导入导出/快捷键/弹窗）
> 评审方式：走查全部界面与自动化操作录像（build/screenshot-*.png），按严重度分级

## P0 — 阻断性/数据安全问题（已全部修复）

| # | 问题 | 修复 |
|---|------|------|
| 1 | 图片节点文本为空白字符时节点渲染成 ~2px 窄条，完全无法点击 | 打开文件自动探测图片尺寸并规范，空白文本自动清理 |
| 2 | Git 绑定时远端同名文件冲突会把冲突标记写进 .cmind，文件损坏 | 冲突时 merge --abort，完整保留本地文件并提示 |
| 3 | 嵌入图片在画布中被放大到 480×360+，版面被撑乱；拖拽手柄易误操作 | 画布内统一缩略图 ≤200×100，移除拖拽手柄 |

## P1 — 本轮已实施

| # | 问题 | 方案 | 状态 |
|---|------|------|------|
| 1 | 「新建脑图/文件夹」按钮在侧栏**底部**，树一长就被滚走；且新建项排在最上面，按钮却在最下面，动线断裂 | 移到文件区**顶部工具条**（🧠＋ / 📁＋，sticky 不随滚动消失），紧邻「新建于：xxx」提示；与"新项排最上"形成闭环 | ✅ |
| 2 | 看图弹窗默认 100% 显示，与"看大图"目的相悖 | 打开即**铺满弹窗**（等比 fit，小图放大、大图缩小），100% 降级为按钮 | ✅ |
| 3 | 看图弹窗全屏遮罩压迫感强 | 改为 **72%×70% 悬浮卡片**（上限 1120×760），半透明背景、圆角阴影、标题栏可拖动 | ✅ |
| 4 | 图片可点击看大图但无视觉暗示 | 图片 hover 光标 zoom-in；工具栏 🔍 悬浮提示；右键菜单入口 | ✅ |
| 5 | 🔍 在未选中图片节点时无意义 | 无图片节点时禁用（降透明度+禁点） | ✅ |

## P2 — 建议后续迭代（未实施）

1. **工具栏分组**：撤销/重做｜节点操作｜插入｜视图｜模式｜导出 之间加分隔线，降低视觉噪音
2. **树行悬停快捷操作**：重命名/删除以图标浮现在行尾，减少右键依赖
3. **看图弹窗**：支持 ⌘+滚轮/触控板捏合、百分比输入框、左右键翻看同图多节点
4. **空状态引导**：首次启动给「三步上手」卡片而非纯空列表
5. **深色模式**与跟随系统
6. **键盘可达性**：所有按钮 Tab 可达并有焦点环；弹窗焦点圈定
7. **标签页**：中键关闭、拖拽排序、溢出滚动
8. **导入/导出**：完成后提供「打开所在文件夹」按钮

## 维持现状（设计合理，无需改动）

- 画布快捷键与 Xmind 对齐（Tab/Enter/⇧Tab/Del），⌘? 帮助可查
- 树按创建时间倒序 + 新建于提示
- 自动保存 + 未保存脏标记（标签页圆点）
- 脑图间链接点击新标签打开
